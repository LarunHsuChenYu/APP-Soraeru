# Soraeru

空耳外語學習產品（暫名 Soraeru／空耳聯合國）的領域名詞表。  
**Status**: Station 1 已收斂（含 ADR-0007 Client-first 單字本、ADR-0008 本機短路）；規格見 `docs/specs/`。

## Meta

**ADR（Architecture Decision Record／架構決策紀錄）**:
紀錄「為何選這條路、不選哪條」的短文，方便之後不靠聊天回憶。**不是**產品功能或畫面名稱。詳見 `docs/adr/README.md`。
_Avoid_: 把 ADR 當成要開發的模組名

## Core product

**空耳（近似音）**:
為外語語音造出的、以台灣華語母語者可記為目標的諧音記憶素材；不是正式音標、也不是譯音規範。
_Avoid_: 拼音備註（當指空耳時）、翻譯、正式讀音

**正式讀音**:
詞彙在來源語言的標準發音表示（文字／可播放音訊），與空耳分開。
_Avoid_: 空耳、近似音

**單字卡**:
使用者選定一個空耳候選後保存的一筆學習條目（含原詞、語言、詞義、讀音、選定／編修後的個人空耳等）。在 **App** 上以**本機為真相來源**；與帳號會合時經可選雲端同步，而非「Server 永遠擁有該卡」。
_Avoid_: 筆記（泛稱）、收藏（除非指列表動作）、把單字卡等同已驗證空耳

**單字本**:
學習者自己的單字卡集合（列表／詳情／刪除／編修）。未登入時可離線**唯讀**本機既有資料；**寫入需登入工作階段**（已登入可離線寫本機，連線後同步）。
_Avoid_: 策展庫、已驗證空耳表

**本機真相來源（Client-first）**:
App 上單字卡以裝置本機儲存為權威；雲端僅備份／多裝置會合用。見 ADR-0007。
_Avoid_: Server-owned notebook（已放棄為長期形狀）、把同步說成即時协同

**雲端鏡像**:
登入帳號在 Server 上的單字卡副本，供備份、多裝置最終一致同步，以及 Web MVP1 過渡期持久化。既有 Server 單字卡列屬此角色，不是 App 的長期 SoT。
_Avoid_: 第二套業務庫、把鏡像叫成已驗證空耳

**單字本同步**:
已登入客戶端與雲端鏡像之間的推拉，目標為多裝置**最終一致**（開 App／前景；非即時）。合併＝穩定卡 ID 聯集＋整卡 LWW；刪除以 tombstone 傳播。
_Avoid_: 即時协同、CRDT、未登入上傳

**整卡 LWW**:
同一卡 ID 兩邊都改過時，以較新的更新時間整筆採用一方；不做欄位級合併、本階段不問使用者。
_Avoid_: 欄位級合併、手動三路合併（本階段）

**Tombstone（刪除墓碑）**:
單字卡軟刪標記（含時間），同步後讓其他裝置刪除同一卡；較新的 tombstone 勝出。刪除帳號時該使用者雲端單字本（含墓碑）一併清除。
_Avoid_: 只硬刪導致他機「復活」舊卡

**分析**:
對一筆使用者輸入（或 Web／App 手動輸入；App 另可 OCR 選字）呼叫**共用 API** 分析管線，產出偵測語言、詞義、正式讀音與空耳候選；可標示已驗證或 LLM 草稿，並經後處理硬閘。
_Avoid_: OCR、翻譯 API（除非真在翻譯）

**本機短路**:
App 再查一字時，若本機單字本已有相同短路鍵的卡，直接開詳情、不呼叫分析。查重只看本機（不看雲端鏡像）；金標命中不是本機短路。見 ADR-0008／票 18。

_Avoid_: 用已驗證空耳庫當「已有卡」、未同步就假定雲端有卡可開

**重新分析**:
單字卡詳情上的明確動作：進入分析／結果流以再產候選；計入額度，並受同字重產上限約束（票 09）。入口與短路邊界見票 18。不是本機短路。
_Avoid_: 把結果頁 ForceRefresh 說成另一套無關額度的路徑

**額度**:
以登入使用者為主體的每日（或方案內）可分析次數上限。App 與 Web 學習端共用同一帳戶額度語意。
_Avoid_: 匿名裝置配額（MVP 已改為登入主體）

**共用 API**:
App、Web 學習端、策展端背後同一套 ASP.NET 後端；學習能力與策展管理能力以授權區分，而非另起第二個後端。
_Avoid_: 各客戶端各自後端

## Trust & quality

**金標（空耳金標）**:
人工依實際聽感核定的「理想空耳」參考答案；作為測評基準，並可升成已驗證空耳餵入產品。
_Avoid_: 正確翻譯、標準音標

**已驗證空耳**:
經策展者核定、可供學習端查詢命中的空耳條目。最小欄位：語言、原詞（正規化鍵）、`displayText`、`notationText`、`explanation`、啟用／下架。**不含**強制詞義／正式讀音（命中時該兩類仍可走 LLM）。
_Avoid_: 開發者平台條目、快取（泛稱）、僅測評用金標（未上架者）

**金標優先覆寫**:
分析時若原詞＋語言命中「啟用中」的已驗證空耳，則空耳相關欄位（displayText／notationText／explanation 等）直接來自該條目且**不呼叫 LLM 產空耳**；詞義與正式讀音仍可呼叫 LLM（或其他既有來源）。**不**強制覆寫使用者單字卡上已保存的個人空耳。
_Avoid_: 混合置頂、整包靜態（本階段未採）；用金標回寫／覆蓋已存單字卡

**LLM 草稿標示**:
學習端對**非**已驗證命中、而由 LLM 產出的空耳，須額外標示為 AI 草稿／未經聽感核定（文案可調）。
_Avoid_: 已驗證（當內容來自策展命中時）

**後處理硬閘**:
對 LLM 產出的空耳候選，在回傳學習端前強制檢查（至少：兒化／不當「兒」「爾」、孤立拉丁／非許可腳本殘渣等）。不合格則拒收該次輸出並依政策自動重試；重試仍失敗則以明確錯誤回使用者，**不得**把未過閘的壞空耳當成功結果顯示。本階段**屬於範圍內**。與 **Prompt 迭代**為雙軌：硬閘擋已知壞形；品質提升多數仍靠持續改 Prompt，而非只寫後過濾程式。
_Avoid_: 只靠文案標示（不足以取代硬閘）；把硬閘說成唯一信任工具

**Prompt 可用性**:
輸出能否被產品管線穩定消費（如 Schema、切段約定）。不等於聽感可信。

**Prompt 可信度**:
輸出是否足以讓使用者相信「這聽起來像原詞」。不足時以金標覆寫＋草稿標示＋後處理硬閘組合緩解；同時以 Prompt 版本迭代（例：`word-analysis.v1.3` 三步內部核對／拉丁黑名單／兒化白名單）作為**主連續改善槓桿**。
_Avoid_: 以為一次 Prompt 定稿後只剩後處理

**信任債**:
已知會傷害聽感信任的系統性問題。開放多語下以標示＋硬閘＋點狀已驗證空耳降低暴露，並靠 Prompt 迭代壓低源頭壞輸出；硬句聽感天花板仍可能不足。

## Surfaces

**學習端**:
一般學習者使用的介面族：Android App，以及 Web 學習端。
_Avoid_: 策展端、Developer Platform

**Web 學習端**:
瀏覽器學習介面（Blazor）；App 為 canonical，Web 為一級學習通道（類 Duolingo：可登入走同一產品學習路徑）。MVP1 **薄頁面**：登入、手動輸入、分析結果、單字本。**不含**相機／相簿／裝置 OCR（本切片）。分析／帳號／額度經共用 API 與 App 對齊；單字本在 MVP1 **暫以雲端鏡像**為該端持久化（非瀏覽器 Client-first 終極形狀，見 ADR-0007）。後續可往功能 parity 演進，但不起第二套玩具產品。
_Avoid_: 策展端、把 Web 說成永久二等玩具、要求 MVP1 即與 App 全功能對等；把 Web 過渡鏡像說成 App 也 Server-owned

**策展端**:
獨立部署的 Blazor 站，經共用 API 對已驗證空耳做最小 CRUD。Google 登入＋email 允許清單。**不是** Developer Platform。
_Avoid_: Developer Platform、開發者平台

## Roles

**學習者**:
使用學習端分析、收藏單字卡、受額度約束的使用者。

**策展者**:
可進策展端維護已驗證空耳的人。現階段＝Google email 允許清單（可與既有開發者允許清單對齊）；**社群投稿明確延後**；投稿審核閘現階段不設計。
_Avoid_: Developer（口語）、任意登入使用者、社群貢獻者（尚未開放）

## Monetization（混合獲利 · v2.1）

**PlanTier（方案階梯）**:
使用者訂閱與權益層級：`Free` 或 `Pro`。由 `GET /me` 回傳；App 不自行推斷 VIP 狀態。
_Avoid_: 在客戶端快取過期的 Pro、混用點數餘額概念

**Billing Anchor（訂閱週期錨點）**:
Pro 訂閱的週期起算日（與 Play／TapPay 扣款對齊）。**AI 圖 30 次額度**於每個 Anchor 續訂日重置，**非**自然月 1 號。
_Avoid_: 用日曆月 `yyyy-MM` 當 AI 圖重置鍵、8/30 訂閱 9/1 又刷額的漏洞

**AdBonusQuota（廣告贈送額度）**:
當日透過 **Rewarded Video** 完整觀看並經 **SSV** 驗簽後，額外可用的文字分析次數（每則 +2，每日最多 3 則）。先扣 `DailyFreeQuota` 再扣本欄位。App 須在 SSV 入庫前 **輪詢 `/me`**，不可立刻分析。
_Avoid_: 未驗簽就加額、把廣告額度當成 AI 圖額度、SSV 延遲時立刻重播廣告

**SubscriptionGuard（訂閱閘）**:
後端守衛：僅在 `PlanTier=Pro` 且訂閱未過期時允許 **AI 圖候選** 等 Pro 專屬 API；與混合日額的 `QuotaService` 分開。
_Avoid_: 用 PaymentGuard 名稱（本專案為訂閱制）、讓 Free 透過廣告解鎖 AI 圖

**AI 圖候選（Vision 候選字）**:
Pro 專屬：上傳圖片至 `POST /image/candidates`，Vision 回傳多個候選外語字；使用者選一字後走既有文字空耳分析。**30 次/訂閱週期**；**0 候選不扣額**。
_Avoid_: 一段式 Vision 直接產空耳、Free OCR 路徑上傳原圖、空白圖仍扣 AI 圖次數

**單字卡唯讀鎖定（Notebook Read-Only Lock）**:
Pro 過期或上限降級後，若卡片數超過當前 `NotebookCardLimit`，既有卡可查複習但 **禁止新增**，直到刪減至上限以下或重新訂閱 Pro。
_Avoid_: 降級時強制刪卡、 silently 阻擋查閱

**Anti-Steering（Play 導外禁令）**:
Google Play 政策：App 內不得引導使用者至外部網站購買較便宜的數位訂閱。TapPay 僅供 **Web 官網**；Android App 僅 Play Billing。
_Avoid_: 設定頁放 pay.soraeru.com、「官網更便宜」文案

**SSV（Server-Side Verification）**:
AdMob 獎勵廣告的伺服器端 ECDSA 簽章驗證；`GET /ads/admob-ssv-callback` 通過後才增加 `AdBonusQuota` 並寫入 `AdRewardLogs`。
_Avoid_: 僅信客戶端 `onRewarded` callback、未記錄稽核
